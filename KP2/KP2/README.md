# Как добавить в решение
1. Распакуйте архив рядом с решением.
2. Правый клик по решению → Добавить → Существующий проект → `KP2.csproj`.
3. Правый клик по проекту → Назначить запускаемым → F5 (при первом запуске нужен интернет для NuGet-пакета `Microsoft.Data.Sqlite`).

Готовая база `smart_home.db` лежит рядом с `.csproj` и копируется в `bin` при сборке.
Если нужно создать базу самому: в DB Browser for SQLite откройте новую базу `smart_home.db`, на вкладке Execute SQL вставьте содержимое `smart_home.sql`, выполните и нажмите Write Changes.

Что не хранится в БД и считается в коде: точность датчика (из Id), запас по нагрузке исполнителя (мощность × 1,25), паспорт устройства (серийный номер `SN-0000N`).

# Ответы на контрольные вопросы

**1. override и new.**
`override` заменяет виртуальный метод: вызов через ссылку базового класса всё равно выполнит версию наследника (полиморфизм). `new` скрывает метод: версия определяется типом ссылки. Через `Device` вызовется `Device.Describe()`, через `SmartActuator` вызовется `SmartActuator.Describe()`. Кнопка «override и new» на вкладке 1 показывает оба случая.

**2. Явная реализация интерфейса.**
Нужна, чтобы метод интерфейса не торчал в публичном API класса (`device.GetExportData()` не скомпилируется) и чтобы развести методы с одинаковыми именами из разных интерфейсов. Вызов: `((IExportable)device).GetExportData()` или через переменную типа `IExportable` (в том числе после `device is IExportable e`).

**3. Shallow и Deep Copy.**
Поверхностная копия (`MemberwiseClone`) копирует поля как есть: вложенные объекты остаются общими, и изменение паспорта у копии меняет оригинал. Глубокая копия создаёт новые вложенные объекты (`Passport.DeepCopy()`), копия полностью независима. Дополнительно у копии обнуляется событие `StatusChanged`, чтобы подписчики оригинала не получали уведомления от неё.

**4. `?.Invoke()`.**
Ссылка на делегат читается один раз во временную переменную: если подписчиков нет, вызова не происходит (нет `NullReferenceException`), а если другой поток успел отписаться между проверкой и вызовом, всё равно вызывается копия. Сами обработчики эта запись потокобезопасными не делает.

**5. Два OrderBy и ThenByDescending.**
Второй `OrderBy` заново сортирует всю последовательность и отбрасывает порядок первого. `ThenBy` / `ThenByDescending` упорядочивают элементы только внутри групп, равных по предыдущему ключу: `OrderBy(Floor).ThenByDescending(Power)`.

**6. async/await, Task.WhenAll, ValueTask.**
`async/await` — способ не блокировать поток во время ожидания (UI остаётся живым); сам по себе он ничего не распараллеливает. `Task.WhenAll` ждёт сразу несколько уже запущенных задач, которые идут одновременно, и возвращает массив результатов: 8 датчиков опрашиваются за время самого долгого, а не за сумму. `ValueTask<T>` выгоден, когда результат часто готов сразу (кэш показаний): тогда не создаётся объект `Task`. Его нельзя ожидать дважды.
