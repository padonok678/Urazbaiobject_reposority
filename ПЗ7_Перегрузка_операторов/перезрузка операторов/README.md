# ПЗ7. Перегрузка операторов, приведение типов, составное присваивание

Консольный проект на C# (.NET 9).

## Что внутри
- `Money.cs` и `CurrencyRecord.cs`: задания 1 и 2 (операторы +, -, сравнение, true/false, implicit/explicit).
- `AccountBalance.cs` и `PremiumAccount.cs`: задание 3 (изменение объекта на месте, virtual/override).
- `Program.cs`: проверка всех операторов с выводом в консоль.

## Как запустить
1. Открыть `ПЗ7_Перегрузка_операторов.sln` в Visual Studio.
2. Нажать F5.

## Примечание про C# 14
Нестатические операторы `+=` и `++` появились в C# 14 (.NET 10). Проект сделан на .NET 9,
поэтому в задании 3 вместо `operator +=` использованы методы `Add` и `Increment`
(объект так же меняется на месте, `virtual/override` работает так же).
