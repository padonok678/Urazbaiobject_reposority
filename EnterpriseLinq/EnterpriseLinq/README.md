# Как добавить в решение
1. Распакуйте архив рядом с решением.
2. Правый клик по решению → Добавить → Существующий проект → `EnterpriseLinq.csproj` → Назначить запускаемым → F5.
   При первом запуске нужен интернет для NuGet-пакета `Microsoft.Data.Sqlite`.

Готовая база `enterprise.db` лежит рядом с `.csproj` и копируется в `bin` при сборке.
`DatabaseInitializer` (этап 1 задания) при запуске создаёт таблицы и стартовые данные, только если базы нет или она пустая.
Для ручного создания базы в DB Browser for SQLite выполните содержимое `enterprise.sql`.

# Ответы на контрольные вопросы

**1. Deferred и Immediate.**
Отложенный запрос (`Where`, `Select`, `Join`...) только описывает вычисление и выполняется при переборе, каждый раз заново и по актуальным данным. Немедленное выполнение (`ToList`, `Count`, `Sum`...) выполняет запрос сразу и сохраняет результат. Если сделать `ToList()` после чтения из БД, дальнейшая работа идёт по уже загруженной копии в памяти, без повторных обращений к базе и без новых изменений. Кнопка «Deferred и ToList()» на вкладке 2 показывает оба случая.

**2. Join и GroupJoin.**
`Join` возвращает плоский список пар (одна строка на каждую пару «категория — товар»); категории без товаров исчезают. `GroupJoin` возвращает для каждой категории группу связанных товаров: `IEnumerable<результат>`, где у каждого элемента есть коллекция `IEnumerable<Product>`. Категория без товаров остаётся с пустой коллекцией.

**3. Equals и GetHashCode у Product.**
`Except`, `Intersect` и `Union` сравнивают элементы через `Equals` и хэш-код. Без переопределения сравниваются ссылки: один и тот же товар из разных запросов считается разным объектом, `Intersect` вернёт пустой результат, а `Union` не уберёт дубликаты. Равные объекты обязаны иметь равный хэш: оба метода у `Product` работают по `Id`.

**4. Skip и Take.**
`Skip((page - 1) * pageSize)` пропускает записи предыдущих страниц, `Take(pageSize)` берёт текущую. Сортировка (`OrderBy`) обязательна: без неё порядок элементов не гарантирован, и страницы могли бы пересекаться или терять записи.

**5. DTO через Select.**
DTO содержит только нужные для отчёта поля (в том числе вычисленные: цена со скидкой, сумма сделки), поэтому передаётся меньше данных, не нужно тянуть вложенные сущности целиком, а структура отчёта не зависит от структуры таблиц.
